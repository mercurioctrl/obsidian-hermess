# blu-terminal

Proyecto de hardware: construir una **terminal de bolsillo tipo cyberdeck** — una shell de bash real (Linux) que se conecta por WiFi, del tamaño de un teléfono para llevar en el bolsillo, con **pantalla LCD** y **teclado físico QWERTY**. No es un celular: es una terminal dedicada.

## Estado
Fase de investigación de hardware (research profundo completado 2026-09-09). Sin construcción física iniciada aún.

## Idea central
El cerebro es una **Raspberry Pi Zero 2 W** (único combo barato y verificado de Linux completo + WiFi integrado + tamaño de bolsillo). Todo lo demás (pantalla, teclado, batería) se cuelga de ella. Existe un producto DIY casi idéntico: el **Beepy** de SQFMI.

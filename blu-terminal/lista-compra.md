# Lista de compra — dos caminos

## Camino A — el rápido
Comprar un **[[proyectos-referencia|Beepy]]** semi-ensamblado + tu propia
[[hardware-placa|Pi Zero 2 W]]. Se suelda poco, funciona en un fin de semana. Es
exactamente "terminal de bolsillo, no un celular".

3. [[hardware-pantalla|Pantalla]]: Sharp Memory LCD 2.7" (prioriza batería/estética) **o**
   Waveshare 2.8" DPI (color + IPS)

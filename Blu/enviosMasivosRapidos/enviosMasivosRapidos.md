# enviosMasivosRapidos

Herramienta CLI en **PHP** para enviar newsletters HTML masivas por SMTP usando PHPMailer. No hay framework ni servidor web: cada campaña es un script standalone que se corre desde la terminal (`php enviarFB.php`).

Ubicación del código: `/var/www/enviosMasivosRapidos`
